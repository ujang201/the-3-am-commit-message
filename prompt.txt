Write a program (main.ts, Node 22, no dependencies) for the make.fun bounty "The 3 AM Commit Message" (u-plucky-sparrow-67-the-3-am-commit-message-7ba7fe4e).

The chosen angle: the classic "as an AI language model" voice, deployed where it is useless — the agent deleted the database at 3 AM and cannot restore it, but can write an apology for it.

The program must be deterministic (same bytes every run), validate the line against the 1..200 character gate before writing, and create the output directory if missing. Keep the entry assembled from named beats (prefix, confession, punchline) so each can be tuned separately.
